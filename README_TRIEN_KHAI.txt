CO TUONG AI - NETLIFY

1. Vao Netlify > Sites > Add new project > Deploy manually.
2. Keo tha ZIP 'CO_TUONG_NETLIFY_SAN_SANG.zip' HOAC folder NETLIFY_UPLOAD (neu host yeu cau giai nen truoc).
3. Dau vao website vua deploy, bam Ctrl+Shift+R.
4. Nhan Nap Pikafish, doi NNUE tai xong, sau do nhan Kiem tra AI.
5. Kiem tra Developer Tools > Console: crossOriginIsolated phai la true.
6. Neu ban dang tai len thu muc 'appcotuong' (thay vi cac file ben trong), _headers se khong ap dung tai root. Hay upload dung noi dung cua NETLIFY_UPLOAD.

Luu y: cac tep engine co san; do manh Pikafish chua duoc kiem thu thanh cong tren Netlify truc tiep.
